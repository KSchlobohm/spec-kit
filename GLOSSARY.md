# Glossary

| Term | Meaning |
|---|---|
| PR description assessment | An evidence-based comparison of a PR's description with its cumulative code changes, identifying material omissions and contradictions without judging author intent or general code quality |
| Material change | A change affecting behavior, interfaces, dependencies, execution configuration, permissions, data handling, or meaningful validation that a maintainer would reasonably want disclosed |
| Assessment coverage | The changed files and evidence examined, compared with the complete PR changes; unresolved or inaccessible changes make the assessment inconclusive |
